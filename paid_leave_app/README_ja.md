# 有給管理システム

従業員の有給休暇を管理するローカル動作のWebアプリケーションです。

## 機能

- 従業員マスタ管理（登録・編集）
- 有給付与の自動生成（入社日ベース）
- 有給取得実績の登録（全日・午前休・午後休）
- FIFO方式での消化管理（古い付与から先に消化）
- 自動失効計算（付与から2年）
- 残日数リアルタイム表示
- 全従業員まとめCSV出力
- 完全ローカル動作（インターネット不要）

## システム要件

- Windows 10
- Python 3.11以上
- インターネット接続（初回セットアップ時のみ）

## セットアップ手順（Windows 10）

### 1. Pythonのインストール確認

コマンドプロンプトまたはPowerShellで以下を実行：

```cmd
python --version
```

Python 3.11以上がインストールされていることを確認してください。

### 2. プロジェクトディレクトリへ移動

```cmd
cd C:\path\to\paid_leave_app
```

### 3. 仮想環境の作成

```cmd
python -m venv venv
```

### 4. 仮想環境の有効化

```cmd
venv\Scripts\activate
```

プロンプトの先頭に `(venv)` と表示されれば成功です。

### 5. 依存パッケージのインストール

```cmd
pip install -r requirements.txt
```

### 6. データベースの初期化

```cmd
alembic revision --autogenerate -m "Initial migration"
alembic upgrade head
```

## 起動方法

### 開発モードで起動

仮想環境を有効化した状態で：

```cmd
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

ブラウザで以下のURLにアクセス：

```
http://127.0.0.1:8000/
```

### Windows用起動スクリプト（便利）

`start.bat` を作成して以下の内容を保存：

```batch
@echo off
echo 有給管理システムを起動しています...
call venv\Scripts\activate
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
pause
```

以降はこの `start.bat` をダブルクリックするだけで起動できます。

## 使い方

### 1. 従業員を登録

1. トップページから「従業員一覧」をクリック
2. 「新規登録」ボタンをクリック
3. 社員番号、氏名、入社日を入力して保存

### 2. 有給付与を自動生成

2つの方法があります：

**方法A: 従業員一覧から全員まとめて生成**
1. 従業員一覧ページで「全員の付与生成」ボタンをクリック

**方法B: 従業員詳細ページで個別に生成**
1. 従業員一覧から対象者をクリック
2. 「付与生成」ボタンをクリック

入社日を基準に以下のルールで自動付与されます：
- 入社6か月後：10日
- 以後1年ごと：11日、12日、14日、16日、18日、20日...
- 8回目以降は毎年20日

### 3. 有給取得を登録

1. トップページまたはナビゲーションバーから「取得登録」をクリック
2. 従業員、取得日、種別（全日/午前休/午後休）を選択
3. 必要に応じてメモを入力
4. 「保存」ボタンをクリック

※残日数が不足している場合はエラーが表示されます。

### 4. 残日数を確認

- **従業員一覧**: 各従業員の現在の残日数を一覧表示
- **従業員詳細**: 付与・取得・残日数の詳細を表示

### 5. CSV出力

1. ナビゲーションバーから「CSV出力」をクリック
2. 出力期間（開始日〜終了日）を指定
3. 「CSVダウンロード」ボタンをクリック

出力内容：
- 従業員ID、氏名、入社日、在籍状況
- 期間内付与合計、期間内取得合計、期間内失効合計
- 現在残日数、直近付与日、次の失効日、次の失効日数

## トラブルシューティング

### ポート8000が既に使用されている

別のポートで起動してください：

```cmd
uvicorn app.main:app --reload --host 127.0.0.1 --port 8001
```

### データベースエラーが発生する

データベースファイルを削除して再初期化：

```cmd
del paid_leave.db
alembic upgrade head
```

### 仮想環境が有効化されない

PowerShellの場合、実行ポリシーを変更する必要があるかもしれません：

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

その後、再度仮想環境を有効化：

```powershell
venv\Scripts\Activate.ps1
```

## 主要な業務ルール

### 取得単位
- 全日：1.0日
- 午前休：0.5日
- 午後休：0.5日

### 付与ルール
- 入社6か月後に初回付与（10日）
- 以後1年ごとに付与日数が増加
- 8回目以降は毎年20日

### 失効ルール
- 付与から2年で自動失効
- 消化はFIFO方式（古い付与から先に消化）

### 残日数計算
- 有効な付与の合計 - 取得実績の合計
- 失効した付与は残日数に含めない
