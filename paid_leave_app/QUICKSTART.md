# クイックスタートガイド

## 最速で動かす手順

### 1. セットアップ（初回のみ）

Windowsの場合、コマンドプロンプトまたはPowerShellで：

```cmd
setup.bat
```

このスクリプトが自動的に以下を実行します：
- 仮想環境の作成
- 依存パッケージのインストール
- データベースの初期化

### 2. サンプルデータ作成（任意）

```cmd
venv\Scripts\activate
python create_sample_data.py
```

9名の従業員とサンプル取得実績が作成されます。

### 3. アプリケーション起動

```cmd
start.bat
```

または手動で：

```cmd
venv\Scripts\activate
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

### 4. ブラウザで開く

```
http://127.0.0.1:8000/
```

## 基本的な使い方

### 従業員を登録

1. トップページ → 「従業員管理」
2. 「新規登録」ボタンをクリック
3. 社員番号、氏名、入社日を入力して保存

### 有給を自動付与

**方法1: 全員まとめて**
- 従業員一覧ページ → 「全員の付与生成」ボタン

**方法2: 個別に**
- 従業員詳細ページ → 「付与生成」ボタン

### 有給取得を登録

1. トップページ → 「取得登録」
2. 従業員、取得日、種別を選択
3. 保存

### CSV出力

1. トップページ → 「レポート出力」
2. 期間を指定
3. 「CSVダウンロード」ボタン

## トラブルシューティング

### エラー: ポート8000が使用中

別のポートで起動：

```cmd
uvicorn app.main:app --reload --host 127.0.0.1 --port 8001
```

### エラー: データベースが壊れた

データベースを削除して再作成：

```cmd
del paid_leave.db
alembic upgrade head
python create_sample_data.py
```

```

├── setup.bat              # 初回セットアップスクリプト

```

## 主要機能

✅ 従業員マスタ管理
✅ 自動付与生成（入社日ベース）
✅ 取得実績登録（全日・午前休・午後休）
✅ FIFO消化管理
✅ 自動失効計算
✅ 残日数表示
✅ CSV出力

## 付与ルール

- 入社6か月後：10日（初回）
- 以後1年ごと：11→12→14→16→18→20日
- 8回目以降：毎年20日
- 失効：付与から2年後

## 消化ルール

- FIFO方式（古い付与から先に消化）
- 全日：1.0日
- 午前休・午後休：各0.5日
