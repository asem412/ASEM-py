# PWA Icons

このディレクトリには以下のアイコンファイルが必要です:

- icon-192.png (192x192ピクセル)
- icon-512.png (512x512ピクセル)

## 推奨デザイン

- 背景色: #0284c7 (プライマリカラー)
- アイコン: チェックマークと歯車を組み合わせたデザイン
- または: グラフと自動化を象徴するロボットアーム

## 簡易的な作成方法

開発時は以下のツールで簡単に作成できます:
- https://www.pwabuilder.com/imageGenerator
- Canvaなどのデザインツール
- Figmaのアイコンテンプレート

## 暫定対応

開発環境では、next-pwaがデフォルトアイコンを生成します。
本番環境では必ず実際のアイコンファイルを配置してください。
